Overview

Pairs and indexes structured evidence records with rendered-page provenance and SHA-256 identity.

  • Artifact
    CaseEvidenceIndexer.js · esm
  • Classification
    host internal
  • Availability
    Node only
  • Normalization
    Normalized naming/page helpers; filesystem errors preserved.

Import and lifecycle

JavaScript
import * as module from '/arcane/modules/CaseEvidenceIndexer.js';

Pure helpers are side-effect free; indexPairedRecord reads raw and Markdown trees, creates the evidence output directory, and writes extracted evidence Markdown.

Application-facing behavior: Eight exported indexing, page, naming, stem, and digest helpers.

Protocol and host implementation

node:fs/promises, node:path, node:crypto This detail does not widen the application-facing API or grant authority.

Parameter meanings and results

Node-only helpers parse structured names, page markers and blocks, safe names, stems, SHA-256, and source-page provenance. indexPairedRecord(options) returns {records, evidence, markdownNames, orphanMarkdown}.

This artifact has no additional documented lifecycle event flow.

Direct coded failures

This artifact exports no Error subclass.

Documented failure behavior

  • TypeError when required roots are absent
  • node:fs, node:crypto, and node:path failures propagate

Availability and capabilities

Node only. Normalized naming/page helpers; filesystem errors preserved.

Node-only host-internal evidence indexing utility; not a browser SDK or Arcane Core bridge.

Contract example

JavaScript
import {parseStructuredRecordName} from '/arcane/modules/CaseEvidenceIndexer.js';

const parsed=parseStructuredRecordName('24-08-26 [Court] - Order.pdf');
console.log(parsed.isoDate,parsed.source,parsed.title);
