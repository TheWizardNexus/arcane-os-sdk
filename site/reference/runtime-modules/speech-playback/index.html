Overview

Segments bounded text, queues latest-request speech synthesis, and controls lookahead HTML audio playback.

  • Artifact
    SpeechPlayback.js · esm
  • Classification
    public first party
  • Availability
    Browser + native bridge
  • Normalization
    State/limits normalized; provider/media failures mixed.

Import and lifecycle

JavaScript
import * as module from '/arcane/modules/SpeechPlayback.js';

Construction attaches ended/play/pause/error listeners to the supplied audio element. prepare() cancels prior work, serializes synthesis per speech client, creates Blob URLs, autoplays when allowed, and prefetches one segment. cancel/stop release URLs; there is no listener-removing destroy method.

Application-facing behavior: SpeechPlayback class/default, voice/limit constants, splitSpeechText(), playback lifecycle APIs.

Protocol and host implementation

Arcane.speech.synthesize, Blob URLs, audio element This detail does not widen the application-facing API or grant authority.

Events, side effects, and errors

Source-literal CustomEvent dispatches

No source-literal CustomEvent dispatch is part of this artifact.

Lifecycle and event flow

  • onState callback snapshots use idle, synthesizing, ready, playing, paused, pausing, buffering, ended, and error states.
  • Consumes audio ended/play/pause/error events.

Direct coded failures

This artifact directly assigns no stable coded failure.

Exported Error subclasses

This artifact exports no Error subclass.

Documented failure behavior

  • TypeError or RangeError for missing audio or invalid/blank/oversize speech input, voice, speed, or pause.
  • Arcane.speech/media errors propagate from prepare() while state becomes error; autoplay rejection becomes played:false.

Availability and capabilities

Browser + native bridge. State/limits normalized; provider/media failures mixed.

Arcane.speech.synthesize uses ai.inference; Blob/audio playback still follows browser media and user-gesture policy.

Behavior example

JavaScript
import SpeechPlayback from '/arcane/modules/SpeechPlayback.js';

const audio = document.body.appendChild(document.createElement('audio'));
audio.controls = true;
const speech = new SpeechPlayback({audio});
const speakButton = document.body.appendChild(document.createElement('button'));
speakButton.type = 'button';
speakButton.textContent = 'Speak';
speakButton.addEventListener('click', async () => {
    await speech.prepare({key:'ready',parts:['Arcane is ready.'],autoplay:true});
});
