Exact names and boundaries

CLI and project reference.

Use the project-local arcane executable supplied by the exact arcane-os npm dependency. arcane-os is the equivalent collision-safe executable name.

Application project files

apps/<id>/arcane-app.json
Canonical schema-2 identity, package policy, permissions, requirements, and targets.
apps/<id>/arcane-package.json
Exact schema-1 projection consumed by the current browser packager.
arcane-packager.json
Positive shared-runtime route map from the installed npm package.
arcane.lock.json
Exact SDK/runtime/protocol identity for the workspace.
dist/<id>/ARCANE_APP_RELEASE.json
Verified browser release inventory; generated, never hand-edited.

Requirements

  • Node.js 22.23.2 or newer; generated CI currently uses Node 24.
  • npm installs the exact project-local SDK dependency and commits package-lock.json.
  • Native targets require an explicit compatible --arcane-root.
  • Use plain JavaScript, HTML, and CSS; no TypeScript toolchain is required.
