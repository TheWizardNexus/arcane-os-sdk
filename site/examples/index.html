Example 02

Create and check an external app

Before the SDK is published, pack the canonical source checkout and pin that exact tarball in the generated repository.

PowerShell or POSIX shell
# In arcane-os-sdk
npm run pack:local
node ./bin/arcane.mjs new field-notes --path ../field-notes --git

# In field-notes
npm install --save-dev --save-exact ../arcane-os-sdk/arcane-os-0.1.0-dev.4.tgz
npm run doctor
npm run check
npm run dev

Result: one external browser application with a committed lockfile and a loopback development server.

Example 03

Check one integrated application

Invoke the SDK from source; do not add the SDK package as a dependency of Arcane OS.

From arcane-os-sdk
node ./bin/arcane.mjs doctor --workspace "../Arcane OS"
node ./bin/arcane.mjs test --workspace "../Arcane OS" --app calculator
node ./bin/arcane.mjs check --workspace "../Arcane OS" --app calculator

Result: evidence for the selected built-in application, not a claim about every Arcane app.

Example 04

Package and verify an exchange bundle

Package first, then bundle the already verified release. Use the filename printed by the command.

External application repository
npm exec -- arcane check --app field-notes
npm exec -- arcane package --app field-notes
npm exec -- arcane verify --app field-notes
npm exec -- arcane bundle --app field-notes
npm exec -- arcane verify-bundle dist/field-notes-0.1.0.arcane-app.tar.gz

Result: one deterministic bundle whose ordered inventory, byte sizes, and hashes agree.

Example 05

Consume stable automation output

Use JSON for one final envelope and NDJSON when an event stream should be processed line by line. Human mode remains the interactive default.

Machine-readable output
npm exec -- arcane doctor --output json
npm exec -- arcane check --output ndjson

Result: stable protocol-framed data on standard output; diagnostic prose stays out of the machine channel.

Example 06

Run one native development target

The descriptor must already declare windows-x64. The explicit Arcane root supplies the compatible provider.

Windows x64
npm exec -- arcane native-doctor --target windows-x64 --arcane-root "../Arcane OS"

npm exec -- arcane run --target windows-x64 --arcane-root "../Arcane OS" --output-root "../arcane-native-output"

Result: a built, exact-SHA-verified, readiness-checked Windows development artifact launched through one process-owned receipt.
