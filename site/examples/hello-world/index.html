Your first Arcane app

Hello World: browser to portable package.

Build a small application with ordinary HTML, CSS, and JavaScript. Use stable Arcane imports, shared styling, app-scoped browser storage, and the same authenticated runtime in development and distribution.

Step 01

Create and install the project

Scaffold the application, enter its directory, and install the exact SDK dependency recorded by the project.

PowerShell
npx arcane-os new hello-world --path ./hello-world --display-name "Arcane Hello World" --target browser --git
Set-Location ./hello-world
npm install

The generated npm scripts use that project-local installation. If you also want the arcane command everywhere in your shell, npm install --global arcane-os is an optional convenience.

Step 03

What Arcane adds

  • CLI: arcane creates, checks, serves, packages, verifies, and runs the application.
  • Browser runtime: theme and primitive styles provide the card and buttons; AppDataScope gives this app its own storage key.
  • Stable imports: the generated browser import map resolves named Arcane modules to the authenticated physical arcane/ tree.
  • Distribution parity: development and dist/hello-world/ use byte-identical runtime files and import-map targets.

App.js imports Arcane by stable names, waits for the shared theme, resolves the application identity, and stores its greeting count in an app-scoped browser key.

apps/hello-world/modules/App.js
import arcaneThemeReady from 'arcane/ThemeBootstrap';
import {
    resolveApplicationId,
    resolveApplicationLocalStorageKey
} from 'arcane/AppDataScope';

const action=document.querySelector('#app-action');
const status=document.querySelector('#app-status');

await arcaneThemeReady;

const appId=await resolveApplicationId();
const countKey=resolveApplicationLocalStorageKey('hello-count',{applicationId:appId});

function loadHelloCount(){
    try{
        const value=Number(globalThis.localStorage?.getItem(countKey)??0);
        return Number.isSafeInteger(value)&&value>=0?value:0;
    }catch{
        return 0;
    }
}

function saveHelloCount(value){
    try{
        globalThis.localStorage?.setItem(countKey,String(value));
    }catch{
        // The greeting still works when browser persistence is unavailable.
    }
}

function sayHello(){
    const count=loadHelloCount()+1;
    saveHelloCount(count);
    status.textContent=`Hello from Arcane OS! Greeting ${count}.`;
}

action?.addEventListener('click',sayHello);

Step 05

Declare the browser contract

The scaffold creates apps/hello-world/arcane-app.json. This static application needs no privileged capability or host method, and its first-release target is explicitly the browser:

arcane-app.json · contract
{
  "permissions": {
    "capabilities": [],
    "methods": []
  },
  "targets": [
    "browser"
  ]
}

Step 06

Check it and run it in a browser

Application repository
npm run check
 npm run dev

You will see: an Arcane-styled page with a working Say hello button. Each click updates an app-scoped greeting count while the named imports resolve from the committed runtime.

Step 07

Package the browser application

Create, verify, and bundle dist/hello-world
npm run package
 npm run verify
 npm run bundle

Output: dist/hello-world/ plus a portable .arcane-app.tar.gz bundle, both containing the application and authenticated Arcane browser runtime.

Step 08

Build and run the browser package

The maintained scripts name the browser target explicitly. build refreshes and packages dist/hello-world/; run verifies that packaged release and serves it on a loopback URL.

Browser build and packaged run
npm run build
 npm run run

You will see: the same greeting application running from the verified packaged browser release. These commands do not create or launch a standalone executable. Standalone native execution is provider-supplied and deferred; it is not part of this first-release walkthrough.
