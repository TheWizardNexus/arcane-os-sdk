From SDK checkout to running app.

This path uses the unpublished development package honestly: verify the SDK, pack it, scaffold one repository, pin the tarball, and run the generated browser app.

1. Check the prerequisites

Use Node.js 22.14 or newer, npm, and Git. Keep the SDK checkout and the app repository as separate real directories. A native target needs a compatible Arcane OS checkout later; the browser quick start does not.

Current publication state

arcane-os is not yet published to npm. Do not run the future npx arcane-os@dev bootstrap until the package exists in the registry.

2. Verify and pack the SDK

Run the repository check before creating the tarball. pack:local deliberately uses npm pack --ignore-scripts, so it packages the already checked source without repeating the complete check; use the filename printed by npm.

arcane-os-sdk checkout
npm ci
npm run check
npm run pack:local

Expected: every source/runtime/test gate exits successfully and npm creates arcane-os-0.1.0-dev.4.tgz.

3. Scaffold one application

Use the source CLI from the SDK checkout. The target is explicit and the generated repository declares browser plus the selected native intent.

arcane-os-sdk checkout
node ./bin/arcane.mjs new local-app --path ../local-app --target portable --git

Expected: one new Git repository containing apps/local-app/, a schema-2 descriptor, the browser package contract, tests, and a generated CI workflow.

4. Pin the packed SDK

Install the tarball as an exact development dependency and keep it at the path recorded by package-lock.json. A local directory dependency is intentionally rejected because npm may turn it into a mutable link.

generated local-app repository
cd ../local-app
npm install --save-dev --save-exact ../arcane-os-sdk/arcane-os-0.1.0-dev.4.tgz
npm ci

5. Check and run the browser app

The generated scripts use the SDK pinned by the app lockfile. The check validates the workspace, descriptor, synchronized runtime, package policy, and app tests before the development server opens.

generated local-app repository
npm run check
npm run dev
Check the terminal and browser.

The check must exit 0. The development command acknowledges first, prints the loopback URL, and owns its server until you cancel it.
