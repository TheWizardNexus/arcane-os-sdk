Full SDK AI lifecycle

Arcane gives language, speech synthesis, and speech transcription separate provider lifecycles. Each role loads, runs, cancels, and unloads without changing the other two.

No external AI model or adapter artifact downloads at import time. A role's network load is the only control that may fetch those external artifacts. Offline load is strict: it uses previously verified app-scoped DBOPFS bytes or reports a cache miss.

Speech authority required: Arcane ships no speech runtime bytes, model weights, or voices. Before using speech, the application must pin immutable, licensed STT and TTS authorities in modules/SpeechAuthorities.js.
